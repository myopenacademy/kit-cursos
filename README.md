# Kit de cursos de MyOpenAcademy

El formato y las herramientas para crear cursos para **MyOpenAcademy**, una academia de programación libre, gratuita y de código abierto que funciona como un juego con DLC: la academia es el juego y cada curso es una expansión que cualquiera puede crear.

- **[`FORMATO.md`](FORMATO.md)**: cómo tiene que ser un curso para que la academia lo pueda instalar.
- **Plantillas y herramientas**: en construcción.
