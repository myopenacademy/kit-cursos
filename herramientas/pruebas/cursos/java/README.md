# Curso de ejemplo de Java

Un curso pequeño de Java que cumple [FORMATO.md](https://github.com/myopenacademy/kit-cursos/blob/main/FORMATO.md), para las pruebas del ejecutor de Java del kit. Empieza por el [índice](00-indice.md).

Los ficheros `entrada.txt`, `args.txt`, `opciones-java.txt`, `termina-con-error.txt`, `salida-variable.txt` y `solo-compilar.txt` de las carpetas de código dicen cómo se comprueba cada programa: lo que se teclea, sus argumentos, sus opciones de Java, que termina con un error a propósito, lo que cambia en cada ejecución y que solo se compila.
